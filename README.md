## ✨ Что внутри

**Главная сцена** — рендеринг чёрной дыры Шварцшильда в реальном времени:
- WebGL-шейдер с интегрированием геодезических (RK4)
- Аккреционный диск с эффектами Доплера и гравитационного красного смещения
- Фотонное кольцо, релятивистские струи, линзирование фона
- Свободная орбита (drag) и масштаб (wheel)

**5 интерактивных экспериментов** (двуязычные, RU/EN):

| # | Модуль | Что показывает |
|---|---|---|
| 01 | **Квантовый ластик** | Эксперимент Кима, Кулака, Шиха (1999) — отложенный выбор |
| 02 | **Бомба Элицура–Вайдмана** | «Измерение без взаимодействия» |
| 03 | **Отложенный выбор Уилера** | Решение измерять путь — уже после щелей |
| 04 | **Две щели · Френель** | Интерференция vs. детектор пути, любой L |
| 05 | **Парадокс близнецов** | Собственное время vs. координатное время |

**Оболочка** стилизована под пульт ЦУП 1990-х: моноширинный шрифт,
фосфорно-зелёный + янтарный, ЭЛТ-скан-линии, LED-индикаторы.
